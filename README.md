# 🧠🖼️ BLIP: Bootstrapping Language-Image Pretraining - Image Captioning & Visual Q&A

This repository contains an implementation of the BLIP (Bootstrapping Language-Image Pretraining) model for two multimodal tasks:

- 🖋️ **Image Captioning**: Automatically generate natural language descriptions of images.
- ❓ **Visual Question Answering (VQA)**: Answer questions based on visual content.

The model leverages pretrained vision-language transformers to understand and reason about images and text jointly.

---

## 📌 Features

- 🔧 captioning and VQA using Hugging Face Transformers.
- 💬 Interactive image + question inputs.
- 🚀 GPU/Colab-ready and optimized for fast inference.
